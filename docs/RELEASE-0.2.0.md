# Yukomon 0.2.0 验收记录

日期：2026-10-19。范围：现有 H5 客户端、HTTP 服务端、卡片效果接入、GitHub Pages 演示。服务器未购买，本轮不含公网后端或小程序审核发布。

## 交付

- Node.js 24 + Express + SQLite 服务；开发会话及微信登录交换接口；用户、媒体、渔获、结算、排行、点赞、分享、导出与删除。完整清单见 `server/README.md`。
- 客户端通过 HTTP 适配层接入；在线发布等待服务端结果，失败保留草稿；幂等重试；连接/断开与本机记录恢复。
- 最新 ReflectiveCard/YukomonFishCard 接入详情、解锁和分享大卡；图鉴与尺寸榜小卡独立保留原样式和 5:7 尺寸，不随大卡更新。
- 短玻璃翻面、像素碎片解锁、像素脉冲与玻璃泛音；跳过、键盘、静音、减少动态效果和组件销毁清理。
- 渔获编辑，删除后收回巨物状态，修复 UR 筛选和进度分母；示例来源不计有效排行；媒体读取取消与过期任务处理。
- Docker/Compose、环境变量示例、备份脚本和微信原生 API 传输层。

## 界面修正

- 设置从图鉴左上角头像与昵称区域进入，移除右上角设置图标，支持键盘 Enter/Space。
- 品质标签统一由 `yk-rarity` 通用组件提供：无底板、Georgia 英文衬线字体，N 雾灰 / R 冷银 / SR 珠光 / SSR 鎏金 / UR 全息；深浅背景分别配色。SSR 为拉丝金属与间歇扫光，UR 为全息膜流彩与反射，材质只显示在字形内部。覆盖统计、小卡、大卡、筛选、选鱼、详情、分享和解锁预览；保留小卡独立的原有布局与 5:7 尺寸，系统减少动态效果时回退静态材质。
- 分享背面完整显示照片，描述、日期、城市和作者使用浅色文字；长内容只纵向滚动，不横向溢出。补充 1440、390、360、320 宽度和横/竖/方照片、长描述检查。
