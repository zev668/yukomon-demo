## 2. 稀有度判定依据

稀有度由以下 4 个因素综合人工评定（不是生物学上的濒危程度）：
1. **分布广度**：全国常见 → 只在某流域/某省份。
2. **栖息地门槛**：城市河塘 → 山溪、冷水、边疆水系。
3. **钓获难度**：台钓随手可得 → 需要专门的路亚/活饵/夜钓/冰钓技巧。
4. **野生个体稀缺度**：养殖逃逸常见 → 野生资源明显下降。

上线后可用全服打卡数据校准：若某鱼种实际钓获率明显偏离预期，按季度调整稀有度（已获得的卡保留原稀有度）。

## 7. 地区性禁钓提示

- **长江流域重点水域十年禁渔**（2021 年起）：长江干流、重要支流及大型通江湖泊（鄱阳湖、洞庭湖）的禁捕水域内，各地对垂钓有不同的限制（一人一竿一线一钩、禁止路亚/拟饵等）。打卡定位落在长江流域时显示提示，引导用户遵守当地规定。
- **青海湖**全面禁捕。
- 各地春季禁渔期（通常 3–6 月，各省不同）：打卡时间与地点命中时提示。
